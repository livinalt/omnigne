# Security

This starter has no live signing or submission path. Contract sources are scaffolds and are not audited executors.

Report security issues through the repository's private vulnerability reporting feature if the owner enables it. Avoid public issues containing credentials, wallet keys, seed phrases or details of an unresolved exploitable issue.

Before a funded deployment, review authorized callers, callable contracts, input limits, protected assets, financing obligations, user signature scope, callback identities and recovery behavior. Include loss budgets and reconciliation for failed and unknown transactions.
